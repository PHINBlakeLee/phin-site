🔒
안전한 건강관리 서비스

PHIN은 건강 데이터를 개인화된 건강관리 코칭에만 사용합니다. 제3자 광고·마케팅 목적 제공은 없습니다.

⚕️
의료 서비스가 아닙니다

PHIN의 모든 분석·점수·추천은 생활습관 관리 정보입니다. 의료 진단·처방을 대체하지 않으며, 건강 이상 시 반드시 의료 전문가와 상담하세요.

🤖
AI 분석은 참고용입니다

AI 기반 건강 분석 및 코칭 내용은 개인화된 참고 정보이며, 최종 건강 결정은 이용자 본인과 의료 전문가가 합니다.

제1조. 수집하는 개인정보 항목
필수 수집 정보
  • 계정 정보: 이메일 주소, 비밀번호(암호화 저장), 닉네임
  • 기본 신체 정보: 성별, 나이, 키, 체중, 허리둘레
  • 생활습관: 수면 시간, 운동 빈도, 음주·흡연 여부, 식습관, 노동 시간
  • 심리성향: MBTI 유형 또는 16가지 성향 선택 결과
선택 수집 정보
  • 경제 지수: 월 건강지출 수준, 소득 범위 (건강관리 추천 최적화에 사용)
  • 가족력 · 병력: 가족력, 과거 병력, 복용 약물
  • 건강검진 결과: OCR 촬영을 통한 혈압·혈당·지질 수치
  • 스마트기기 연동: 걸음수, 수면 세션, 심박수, 소모 칼로리 (Health Connect 경유)
  • 여성 건강: 생리 주기 정보 (여성 이용자 선택 시)
  • 식단 사진: AI 영양 분석을 위한 식사 사진
자동 수집 정보
  • 앱 사용 기록: 기능 사용 이력, 운동 완료 기록, 점수 변화 이력
  • 기기 정보: 운영체제, 앱 버전 (오류 진단 목적)
제2조. 개인정보 이용 목적
  • PHIN스코어(0~100점) 산출 및 신체나이·동년배 비교 제공
  • 개인 맞춤 운동·식단·수면 코칭 생성
  • 레드라인 안전 시스템 운영 (위험 지수 임계값 초과 시 전문가 상담 안내)
  • 티어(GRAY → THE PHiN) 및 커뮤니티 기능 제공
  • 주간·월간 건강 리포트 생성
  • 서비스 오류 진단 및 개선
  • 법령상 의무 이행

수집된 정보는 위 목적 이외에 사용되지 않으며, 목적 변경 시 별도 동의를 받습니다.

제3조. 개인정보 보유 및 이용 기간
  • 회원 탈퇴 시: 즉시 전체 삭제 (18개 테이블 cascade 처리)
  • 건강 데이터만 선택 삭제: blake@phin.health 이메일 문의 → 10일 이내 수동 처리
  • 법령 보관 의무: 관련 법령이 정한 기간 동안 보관 후 파기

건강정보(민감정보)는 별도 암호화 저장하며, 탈퇴 즉시 복구 불가하도록 완전 삭제합니다.

제4조. 건강정보(민감정보) 특별 보호

건강검진 결과, 병력, 생리주기, 흡연·음주 정보는 「개인정보보호법」상 민감정보로서 아래와 같이 특별 보호합니다.

  • 전송 시 TLS 암호화, 저장 시 암호화 처리
  • PHIN스코어 계산·코칭 목적 이외 사용 금지
  • 외부 제3자에게 마케팅·광고 목적으로 제공하지 않습니다
  • 내부 접근 권한 최소화 원칙 적용
제5조. 개인정보 처리 위탁 (외부 서비스)
Supabase 데이터베이스 및 인증
  • 위탁 목적: 사용자 계정 인증, 건강 데이터 저장·관리
  • 서버 위치: 대한민국 서울 리전 (ap-northeast-2)
  • 보관 기간: 회원 탈퇴 시까지
OpenAI AI 코칭 분석
  • 위탁 목적: AI 건강 코칭 텍스트 생성, 식단 사진 분석, 건강검진 OCR
  • 전송 정보: 건강 데이터 요약본 (닉네임·나이·건강지수 등)
  • 데이터 보관: 전송 후 최대 30일 자동 삭제 (OpenAI API 기본값)
  • 모델 학습 사용 여부: 미사용 (API 기본 정책)
  • 익명화: 별도 익명화 처리 없이 요약 데이터 전송 (API 키 서버 측 격리 보관)
Kakao 소셜 로그인
  • 위탁 목적: 카카오 계정을 통한 간편 로그인
  • 전송 정보: 카카오 계정 식별자 (건강 데이터 미전송)
Google Health Connect 스마트기기 연동
  • 위탁 목적: 스마트워치·밴드의 걸음수·수면·심박수·칼로리 데이터 수집
  • 이용자 직접 권한 설정 (Health Connect 앱에서 언제든 해제 가능)
제6조. 이용자의 권리와 행사 방법

이용자는 언제든지 아래 권리를 행사할 수 있습니다.

  • 열람: 수집된 개인정보 확인 (앱 내 프로필 화면)
  • 수정: 부정확한 정보 정정 (앱 내 직접 수정)
  • 삭제(전체): 앱 설정 → 계정 삭제 → 즉시 전체 삭제
  • 삭제(건강데이터만): blake@phin.health 이메일 문의 → 10일 이내 처리
  • 처리정지: blake@phin.health 이메일로 요청
  • Health Connect 권한 해제: Health Connect 앱 → 앱 권한 → PHIN → 권한 해제

만 14세 미만 아동의 개인정보는 수집하지 않습니다.

제7조. 서비스 한계 및 책임 범위
  • PHIN은 의료법상 의료기기·의료서비스가 아닌 비의료 건강관리 서비스입니다
  • PHIN스코어·신체나이·건강 분석은 생활습관 관리 정보이며, 의학적 진단이 아닙니다
  • 건강 이상이 의심될 경우 반드시 의료 전문가의 진료를 받으세요
  • 이용자가 제공한 정보가 부정확한 경우 분석 결과도 부정확할 수 있습니다
  • 이용자 본인의 건강 결정에 대한 최종 책임은 이용자에게 있습니다
