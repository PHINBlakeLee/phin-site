# PHIN official website — phin.health

PHIN (Personal Health INtelligence) is a health-coaching app from South Korea. It turns lifestyle, body-composition, health-checkup and activity data into a single 0–100 PHIN Score, compares users with their age peers, and coaches them day to day. This repository is the source of the public website at [phin.health](https://phin.health) (served via GitHub Pages): the Korean landing page with the 30-second PHIN Score check, the English company page ([about.html](https://phin.health/about.html)) and the privacy policy. The Android app is available on [Google Play](https://play.google.com/store/apps/details?id=com.phin.health). Contact: blake@phin.health.
